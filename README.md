# 高性价比人生指南 · 分类速查

一个单页静态站点，把 [HowToLiveBetter](https://github.com/eternity4719/HowToLiveBetter)（《高性价比人生指南》）的 608 条建议按 7 个大类重新归好类，方便按需检索。

## 功能

- 7 大类：保命与健康、省钱与理财、法律与安全、工作与赚钱、家庭与人生阶段、精力与时间、安居出行与选择
- 搜索：支持多关键词（空格分隔），匹配标题、正文、成本、收益、章节名
- 筛选：不花钱 / 不用毅力 / 收益大 / 证据 A 级 / 算生死账，可叠加
- 排序：按章节顺序 / 收益大的在前 / 证据硬的在前
- 每条可展开查看：成本、收益、备注、来源原文

## 说明

- 条目文字、成本、收益、证据等级、来源均照抄原书，本页只做重新归类与检索，未改写内容。
- 单文件、零外部依赖、无统计脚本、无 Cookie，可离线保存使用。
- 内容不构成医疗、法律或投资建议，原文即如此声明。
